About AI Assistive Tutor

Multimodal Machine Learning Architecture for Inclusive Education.

Project Specifications:

  • Object Detection: FieldNet V3 (PyTorch, ResNet-34 backbone, 128 channels, 416x416 resolution, pre-trained on classroom dataset).
  • Text Extraction: OpenCV preprocessing + Tesseract OCR Engine (PSM 3 segmentation).
  • Spoken Audio Narration: Native macOS say utility + Web Speech API with fallback.
  • Academic Tutoring: Google Generative AI (Gemini 1.5 Flash) with contextual textbook grounding.
  • Session Persistence: SQLite with PBKDF2-HMAC password hashing and foreign-keyed audit logs.

Status: All backend pipelines operational and integrated.
